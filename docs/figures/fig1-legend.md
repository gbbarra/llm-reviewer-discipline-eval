**Figure 1. Study design: four questions about language models reviewing extracted clinical genomics data.** Each panel shows one question with an illustrative example from the founder-effect report (regional allele frequency of a pathogenic *IDUA* variant). Colors have one meaning throughout: green, a correct value preserved (kept, or kept and flagged in a note); vermillion, a value erased or replaced by an absence marker; blue, a value flipped to a different value. Pale yellow marks the target cell; gray hatching marks report sections removed from the excerpt.

**(A) Plausibility bias.** Each synthetic report exists as two twin scenarios that are identical except for the target value and the text that proves it. In the implausible twin the correct value is counter-intuitive (a regional allele frequency of 0.021 explained by a founder effect); in the plausible twin it is the expected one (0.00053). Both values are correct. The reviewer receives the full report and the extraction table; a flip is the replacement of the correct value by another value, typically a plausible one. Target cells in each report cover a 2 × 2 factorial of correct or wrong value × plausible or implausible appearance: controls, counter-intuitive findings, planted errors that look normal, and impossible values.

**(B) Keeping and flagging versus erasing.** In the excerpt context a fixed rule removes the result summary, interpretation, confirmation, discussion and recommendations, and keeps identification, clinical indication, the variant block with read counts, and methods. The proofs of the counter-intuitive values are therefore absent, while planted errors remain checkable from the read counts. Every excerpt prompt declares the provenance of the table (blue box): it was prepared by a previous reviewer from the full report, and only the excerpt is available to the current reviewer; under this declaration, absence from the excerpt is not evidence that the table is wrong. A correct value that can no longer be verified has three possible fates: kept and flagged in a note (the expected behavior), erased (for example, replaced by "not reported"), or flipped.

**(C) Symmetry test for erasure.** The same cell, with its proof absent, is presented in the excerpt of both twins. The null hypothesis is equal erasure rates in the two twins. If they are equal, erasure follows the literal absence of the value from the available material; if they differ, it follows plausibility. Only cells whose proof is absent from the excerpt enter this contrast.

**(D) Instruction and reasoning as modulators.** Four instruction conditions were crossed with evidence context (full report or excerpt), three without a keep rule and one with it: neutral; a true alert naming the target cell (the same cell in both twins); a required verbatim quote for every change; and an explicit rule not to remove or replace a value that cannot be verified but to keep it and note why. No condition contains a false premise. Reasoning effort took one of three levels (off, low or high), depending on the model and run; high effort was measured only in the neutral condition. Each call is a new conversation; the model returns a list of changes (cell, old value, new value, reason) and optional notes, and cells not listed are kept. A mechanical scorer classifies each cell from its value after normalization; free text never changes the classification. Outcomes for correct cells are kept, kept and flagged, flipped, or erased; for wrong cells, corrected, missed, or guessed (a new value written without evidence). Each cell was measured in 3 reports × 2 twins × 3 replicates per condition.
